# code by aqeel design

Product name: "code by aqeel" (lowercase), shown in aqeelOS as aqeelOS Code. The app has its own neutral design system (the tokens below); the app heading and browser title use the product name.

Tokens: Plus Jakarta Sans (bundled, no remote font); ink #0b0c10; ink secondary #2e3038; blue #0158cb; blue secondary #2f7bff; blue deep #0a3f8f; pale blue #e8f0fe; border #e2e3e9; surface #fff; soft #f5f6f8; radii 8/12/24px. The mark is the plain aqeelOS mark (assets/aqeelos-mark.svg). An install's own name and logo come from its aqeelOS (System › Branding there).

The app serves the user's own website-building workflow. A project rail, left conversation pane, and right file/preview workspace reflect their requested Codex-like organization. The blue primary action and pale-blue selection states carry the accent; the wordmark sits beside the plain mark. The preview receives the most space. Pane handles allow users to decide the relative width. Tab indicators and short panel transitions show navigation changes. No ornamental motion during reading or editing. Theme toggle preserves user choice. Keyboard resizing, focus outlines, mobile stacking, and reduced motion are required.

ENERGY 1 / RHYTHM 2 / MOTION 2. Shadows only on floating dialogs. Every empty state represents actual saved project data; no invented conversations or progress claims.

## Token set

All four pages (workspace, connections, development board, PRD) use one token set: `--blue #0158cb`, `--blue-2 #2f7bff`, `--blue-deep #0a3f8f`, `--ink #0b0c10`, `--ink-2 #2e3038`, `--border #e2e3e9`, `--soft #edeef2`, `--soft-2 #f5f6f8`, `--sky-1/--sky-2`, radii `--r-sm 8 / --r-md 12 / --r-card 24 / --r-pill`, and `--shadow-card / --shadow-float / --shadow-btn`.

Pill buttons, a blue gradient primary with glow, an eyebrow pill with a blue dot, a 60px frosted header, the mark beside the wordmark, a sky gradient for empty states and the connections hero, uppercase table headers, and 12px inputs with a blue focus ring.

`--muted` is `#646875` (AA on white for the app's 10 to 12px labels). Keyboard focus keeps a 3px `#2f7bff` outline. Dark mode uses the same names. Work panels stay flat and dense; display-size type is limited to empty states and page heroes.
