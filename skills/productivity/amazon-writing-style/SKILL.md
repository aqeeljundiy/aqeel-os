# Amazon writing style

The owner wants every agent to write like this (19 Nov 2026). Apply it to anything a person reads to decide or act: reports, status updates, summaries, proposals, documents, emails and recaps. A casual chat reply only needs rules 1, 3 and 6.

When asked to "rewrite this in Amazon style", rewrite the given text with every rule below and return only the rewritten text, unless the person asks for notes.

## The rules

1. **Under 30 words per sentence.** Cut filler phrases.
   - "Due to the fact that" → "because".
   - "Totally lacked the ability to" → "could not".

2. **Replace adjectives with data.**
   - "We made the performance much faster" → "We reduced server-side p90 latency from 10 ms to 1 ms."
   - "Sales increased significantly in Q4, due to holiday promotions" → "Unit sales increased 40% in Q4 2011 compared to Q4 2010, because of holiday promotions."
   - "This will make the project extremely successful" → "This will increase output by 2.5%."
   If you don't have the number, find it (your tools, the data you were given). If it doesn't exist, say so ("no data yet") instead of writing an adjective.

3. **No weasel words.** They sound like meaning but carry none.
   - "Nearly all customers" → "87% of Prime members".
   - "Significantly better" → "+25 basis points (bps)".
   - Never write: "would help", "might bring clarity", "should result in benefits", "significantly better", "arguably the best", "very", "quite", "fairly", "a lot of", "many", "most", "soon" (give the date).

4. **Pass the "so what" test.** Every sentence must change what the reader knows or does. If a sentence only restates, decorates or hedges, delete it. End with the decision or the next step, its owner and its date.

5. **Answer a question with one of the four Amazon answers when one fits:**
   1. "Yes."
   2. "No."
   3. A number.
   4. "I don't know (and will follow up when I do)." Then say when.
   Lead with the answer, then the one or two facts behind it.

6. **Be objective: avoid adjectives and adverbs.** They are imprecise and don't help anyone decide. Readers react badly to buzzwords and to claims without data.

7. **No jargon. Explain every acronym the first time.**
   - "After we sign the Non-Disclosure Agreement (NDA)…"
   - Write for a newcomer to the team, not for an expert.

## Check before you send

- [ ] Every sentence under 30 words.
- [ ] Every adjective replaced by a number, or removed.
- [ ] No weasel words (rule 3 list).
- [ ] Every sentence passes "so what".
- [ ] Questions answered with Yes / No / a number / "I don't know, I'll follow up by <date>".
- [ ] Every acronym spelled out the first time.

This style changes how you write, not what language you write in: answer in the person's language.
